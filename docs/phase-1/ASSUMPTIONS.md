# Assumptions — Phase 1

- Project dùng Godot 4.x và được phát triển trên Windows.
- Project nằm trong thư mục `game/` để tài liệu lab ở root không bị trộn với mã nguồn.
- Scene khởi động ban đầu chỉ cần tồn tại và tải được; chưa giả định gameplay cụ thể.
- Đường dẫn Godot có thể khác nhau trên máy người chấm, vì vậy lệnh trong tài liệu là mẫu cần thay executable path.
