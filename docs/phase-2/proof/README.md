# Phase 2 evidence

The JSONL files in this directory are raw output from `game/headless.py`.
Their matching scenario and input commands are listed in `tests/README.md`.
Do not edit generated traces by hand.

`gui-main-menu.png`, `gui-night-intro.png`, and `gui-pause.png` are captures
from the running Godot project. `fps-1280x720.txt` records a graphical run at
1280×720. Settings persistence and the full three-night result flow have not
been independently verified; see `../ACCEPTANCE.md` for remaining gaps.
